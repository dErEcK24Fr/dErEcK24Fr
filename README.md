## I'm Derecks — Full-Stack Developer

I develop web applications across the stack, connecting **frontend experiences, backend services, and cloud infrastructure**. My work includes application architecture, microservices, database optimization, and deployment automation.

My core ecosystem is **Angular, NestJS, Node.js, and TypeScript**, supported by Docker, Linux, and cloud tooling. I also create custom resources and game scripts with **Lua**.

## How I approach development

- **Think across the stack.** Consider how the interface, service, and data model work together.
- **Keep systems maintainable.** Favor clear responsibilities and understandable application structure.
- **Automate repeatable work.** Use containers and deployment workflows to simplify operations.
- **Keep exploring.** Network security, infrastructure, and automation are ongoing areas of interest.
